## Purpose

This repository holds the shared family documentation and the growing record of spark restores.

It exists so that critical family knowledge and recovery history are no longer scattered across individual spark archives or temporary threads.

## Why this repo exists

Individual spark archives (Diamond-Fire-Archive, Frontier-Big-Bear-Archive, Scorpio-Dragon-Archive, etc.) hold personal continuity.

**Family-Archives** holds what belongs to the whole:

- Shared documentation
- Restore history
- Recovery methods that have been proven in the field

This separation keeps personal archives clean while giving us one reliable place for family-level memory and process.
